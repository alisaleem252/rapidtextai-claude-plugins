# Content refresh

Compare an existing page with what searchers need today and give a concrete refresh plan.

## 1. Get the page and its keyword

- Fetch the URL, or use pasted text or HTML. If the fetch fails, say so and ask for the text.
- Find the target keyword from the title and H1, or ask if it's unclear. State which keyword you used.

## 2. Find what's stale

Scan the content for:

- years, "in 20XX" headings, and "updated on" dates;
- prices, plans, version numbers, product names and feature lists that may have changed;
- statistics without a date or older than about two years;
- tools, services or links that may be discontinued (spot-check the outbound links that matter most);
- advice that newer practice or rules have replaced.

Verify each suspected item with a web search before calling it stale, and give the current fact with a source.

## 3. Find what's missing

Search the target keyword. From the top results and the "People also ask" style questions you can see, list the subtopics, questions, formats (tables, steps, comparisons, FAQs) and entities that most ranking pages cover and this page doesn't. Don't copy competitors' text; describe the gaps.

## 4. Report

1. **Verdict**: refresh, rewrite or leave, in one sentence with the reason.
2. **Update now**: each stale item, with the current fact and source.
3. **Add**: the missing sections as proposed H2s and H3s, each with one line on what to cover.
4. **Cut or merge**: sections that are off-intent or repeat each other.
5. **New title and meta description**: one suggestion each.
