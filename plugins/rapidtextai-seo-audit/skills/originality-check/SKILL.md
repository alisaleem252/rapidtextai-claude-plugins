# Originality check

Look for copied passages and judge how much original value the content adds. Be clear about the limits: this is a spot check with web search, not a full plagiarism database scan.

## 1. Get the text

Fetch the URL or use the pasted text. Work on the main content only. If the fetch fails, say so and ask for the text.

## 2. Spot-check for copying

- Pick 6–10 distinctive sentences or phrases from across the piece (intro, middle, conclusion, any definition or list that looks lifted). Prefer sentences with specific wording over common phrases.
- Search each one as an exact phrase in quotes.
- For every match on another domain, note the URL and whether the match is exact, lightly reworded or only the same idea.
- If the page is the original (older publish date, or the other sites credit it), say so rather than flagging it.

## 3. Judge original value

Rate each from low to high, with one line of evidence:

- **First-hand experience**: tests, screenshots, results, opinions only the author could have.
- **Original data or examples**: numbers, case studies or examples not found in the top results.
- **Unique angle**: does it say anything the top results for its keyword don't?
- **Generic filler**: stock intros, definitions everyone repeats, padding.

## 4. Report

1. **Verdict**: original, mostly original, partly copied or largely copied, with how many of the sampled sentences matched elsewhere.
2. **Matches**: a table of the sentence (short), matching URL and match type.
3. **Original value**: the four ratings above.
4. **How to fix**: rewrite or cite each matched passage, and two or three specific ways to add original value.

Note the method's limit in one line: phrases you didn't sample can still match other pages.
